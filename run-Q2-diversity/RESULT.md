# RESULT — Q2: разнообразие ансамблей, сэмплер vs мультистарт (формат §30)

## problem
Ценен ли квантовый сэмплер там, где нужен не один оптимум, а АНСАМБЛЬ
структурно-разных хороших решений (рекомендация №2 для сметчика: 2-3 набора
поставщиков)? Q1 закрыл вопрос качества; здесь метрика — разнообразие.

## validation (агент, $0.027, $0 железа)
Инстансы Q1 (n=12/16/20, 3 сида, brute-оптимум известен). Три метода при РАВНОМ
бюджете 8192 оценки: neal-мультистарт, QAOA-сэмплы (Aer), random+greedy. Все
решения через репайр. ε-хорошие: value ≥ 0.95·opt. Разнообразие: число
Хэмминг-кластеров (порог ⌈n/4⌉) + средне-попарный нормированный Хэмминг.

## результат
| n | кластеров neal / qaoa / rnd+greedy | попарный Хэмминг (те же) |
|---|---|---|
| 12 | 1.33 / 1.33 / 1.67 | 0.083 / 0.054 / 0.060 |
| 16 | 1.33 / 1.67 / 1.67 | 0.086 / 0.105 / 0.082 |
| 20 | 1.00 / 1.00 / 1.00 | 0.036 / 0.066 / 0.057 |

## verdict
**«Разницы нет» + более глубокая находка.** Ни один сэмплер не даёт преимущества
в разнообразии. Но число кластеров 1.0–1.7 говорит важнее: **на этих инстансах
ε-хорошие решения СХЛОПЫВАЮТСЯ в один кластер** — богатого поля «разных хороших»
просто нет, все хорошие решения близки по Хэммингу. Вопрос разнообразия на таком
ландшафте плохо поставлен, и квант тут ни при чём.

## применимость к сметчику (рекомендация №2)
Прямой урок: разнообразие наборов поставщиков нельзя НАДЕЯТЬСЯ получить из
сэмплирования — его надо ИНЖЕНЕРИТЬ явно (штраф/фильтр по Хэммингу к уже
найденным), иначе «альтернативные наборы» окажутся почти копией первого. Это
усиливает вывод разбора рекомендаций (docs/RECOMMENDATIONS…): ансамбль без
явного механизма разнообразия вырождается в один вариант.

## strongest_objection
Синтетические QUBO одного типа с плотным ε-оптимумом; на задачах с истинно
мультимодальным ландшафтом (напр. с симметриями) картина может отличаться —
но тогда и брать надо такие инстансы, а не эти.

## Итог квантовой линии (Q1+Q2+Q3)
Карта честная и полная:
- **general-QUBO gate-based (QAOA)** — квант НЕ помогает: проигрывает по качеству
  (Q1) и не выигрывает в разнообразии (Q2). IonQ-бюджет сэкономлен.
- **аналоговые аттракторы (Q3)** — квант ДАЛ реальный результат: паттерны 7-8
  атомов воспроизведены на железе Aquila, разрыв sim↔hw измерен и объяснён.
Вывод для конвейера: квантовый угол искать в аналоговой физике (Rydberg/Ising),
не в gate-QAOA поверх произвольных QUBO. neal остаётся рабочей лошадкой оптимизации.

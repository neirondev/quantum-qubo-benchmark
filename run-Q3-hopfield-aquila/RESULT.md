# RESULT — Q3: аттракторы блокады как модель памяти, симулятор → железо (формат §30)

## problem
Мост великана №2 (память мозга) в физическую плоскость: устойчивые конфигурации
возбуждений (аттракторы блокадного порядка) на аналоговом Rydberg-массиве;
«забывание» = управляемая деградация порядка полем. (phase0-feasibility.md)

## abstraction
Паттерн = целевое максимальное независимое множество; retention = доля шотов с
точным паттерном; деградация = кривые retention от параметров протокола.

## source_domain → transferred_mechanism
Хопфилд/аттракторные сети → аналоговая Rydberg-динамика; честная переформулировка:
произвольных J_ij нет, паттерн задаёт ГЕОМЕТРИЯ (фаза 0).

## validation (три фазы, всё воспроизводимо)
- **Фаза 0**: локальный AHS-симулятор освоен, r-g-r 97.5% на 3 атомах.
- **Фаза 1** (агент, 54 точки, $0.042): кольцо-8 — три кривые деградации
  (полка→обрыв по Δ_end; плавная адиабатическая по t_sweep 0.95→0.15; шумовое
  плато по σ). Линия/кластеры — retention≈0; гейт-контрэксперименты вскрыли
  причину: Δ_end=1.2e8 > V_nn(6.0мкм)=1.16e8 — пробой блокады (плотные упаковки
  в шотах), ниже пробоя — вырождение MIS открытых цепочек + хвосты вторых
  соседей. Исправление: нечётная P7 (единственное MIS) → 86-90% на симуляторе.
  Кольцо работало «случайно»: агент построил его с шагом 5.85мкм (V_nn=1.35e8).
- **Фаза 2** (QuEra Aquila, реальное железо, 2 задачи × 100 шотов, $2.60,
  согласие Дениса, журнал необратимых): ring8 — retention **0.581** (54/93
  загруженных шотов), line7 — **0.573** (51/89). Оба паттерна ДОМИНИРУЮТ в
  измерениях (топ кольца: две альтернации 32+22; топ P7: цель ×51).

## Ключевой количественный результат: разрыв симулятор↔железо
| | симулятор | Aquila | пер-атомная верность f=ret^(1/N) |
|---|---|---|---|
| кольцо-8 | 0.95 | 0.581 | 0.934 |
| P7 (Δ_end=1.1e8) | 0.90 | 0.573 | 0.924 |

Распределение ошибок спадает по Хэммингу (кольцо: 54/19/10/5/5) — деградация
в основном объясняется НЕЗАВИСИМЫМ пер-атомным шумом f≈0.92-0.93 (подготовка/
детекция/потери), а не разрушением коллективного порядка. Аттрактор на железе
ЖИВ: точный глобальный паттерн 7-8 атомов в ~58% шотов.

## verdict
**CONFIRMED (мост построен)**: (1) кривые деградации «памяти» полем сняты на
симуляторе; (2) аттракторные паттерны воспроизведены на реальном квантовом
железе с первой попытки по исправленному дизайну; (3) разрыв sim↔hw измерен и
объяснён пер-атомной моделью шума. Дизайн-правило выведено и проверено железом:
V₂ < Δ_end < V_nn + геометрия с единственным целевым множеством.

## strongest_objection
Одна точка на железе на геометрию (кривые деградации на железе не сняты — $);
хвост ошибок P7 немонотонен (HD3=11 > HD2=4) — возможны коррелированные события
(диабатичность финала/чёрнотельные переходы), пер-атомная модель — первое
приближение. Загрузка атомов 89-93% — постселекция честно указана.

## limitations / уроки
- Квирк железа, которого нет в симуляторе: y-ряды сайтов (0 или ≥4мкм) —
  октагон повёрнут на 22.5°; отклонение валидацией бесплатно.
- Ошибки интерпретации агента пойманы гейтом (битовая конвенция, «фрустрация»,
  рекомендация увеличить шаг) — уроки в память наставника.
- Стоимость всей ветки: $0.042 (LLM фазы 1) + $2.60 (QPU) + $0 (симуляторы).

## next_experiment

кольцо-12 (та же цена за задачу).

## ⚠️ УТОЧНЕНИЕ (2026-09-05, гипотеза №23 подтверждена)
Объяснение разрыва sim↔hw ТОЛЬКО пер-атомным шумом оказалось НЕПОЛНЫМ. Измерение с
удержанием финального поля (0/6/15 мкс) на той же Aquila дало монотонный спад
0.581 → 0.508 → 0.387 (−0.194 ± 0.080, 2.42σ) при ПЛОСКОМ идеальном симуляторе.
Значит есть второй канал потерь — временной распад паттерна, τ ≈ 37 мкс (порядок).
Модель f≈0.93 остаётся объяснением базового уровня при hold=0. См. H23_RESULT.md.

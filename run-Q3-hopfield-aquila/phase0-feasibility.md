# Q3 фаза 0: техразведка Хопфилд-на-Aquila (2026-09-04)

## Снято с железа (паспорт Aquila через Braket SDK)
256 атомов; поле 75×76 мкм; мин. шаг 4 мкм; C6=5.42e-24; Rabi ≤ 15.8e6 рад/с;
detuning ±1.25e8 рад/с. Блокадный радиус при полном Rabi ≈ 8.3 мкм.

## Локальный AHS-симулятор освоен (LocalSimulator "braket_ahs")
Протокол: 3 атома в линию по 6 мкм; амплитуда trapezoid до 15.7e6;
адиабатический свип detuning −1.2e8 → +1.2e8 за 4 мкс.
Результат: r-g-r в 97.5% шотов (200 шотов) — корректный AF-порядок блокады.
Грабля декодирования: post_sequence 1=ground, 0=Rydberg.

## Честная переформулировка эксперимента
Классический Хопфилд с произвольными J_ij НА AQUILA НЕВОЗМОЖЕН: взаимодействия
только антиферромагнитные (блокада), знак и величина задаются ГЕОМЕТРИЕЙ.
Рабочая версия Q3: «паттерн» = устойчивая конфигурация возбуждений, заданная
геометрией кластеров (аттрактор блокадного порядка); «забывание» = управляемое
разрушение порядка полем: финальный detuning ↓ / шумовой участок свипа / скорость
свипа. Метрики: сохранность паттерна (доля шотов с целевой конфигурацией) как
функция «возмущения поля» — кривая деградации памяти. Мост: сравнить форму кривой
c нашей симуляцией UI-001 (retention под нагрузкой) и с данными гиппокампа (A5).

## План фазы 1 (агенту, когда освободится слот)
1. Геометрии: линия 8, кольцо 8, две «ямы»-кластера (конкурирующие паттерны).
2. Локальный AHS: кривые сохранности при вариации final_detuning / t_sweep / шума.
3. Затем ОДИН запуск на Aquila (≤50 shots, после добавления spending limit на Aquila) —
   сравнение с симулятором. Cost-guard, журнал необратимых действий.
